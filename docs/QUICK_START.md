# Quick Start Guide

## Prerequisites
- Node.js 18+
- Telegram Bot Token (get from @BotFather)

## Setup in 3 Minutes

### 1. Clone & Install
```bash
git clone https://github.com/SEIFSEIF4/eghatha_bot.git
cd eghatha_bot
npm install
```

### 2. Configure
```bash
cp .env.example .env
# Edit .env and add your BOT_TOKEN
```

### 3. Run
```bash
npm start
```

## Bot Commands
| Command | Description |
|---------|-------------|
| /start | Initialize the bot |
| /subscribe | Subscribe to a group |
| /poll | Create a new poll |
| /alert | Send alert to group |
| /help | Show help message |

## Deploying to Railway (Free)
1. Push to GitHub
2. Connect repo on railway.app
3. Add BOT_TOKEN environment variable
4. Deploy!
